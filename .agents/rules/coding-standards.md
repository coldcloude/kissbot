# API、配置、时间格式规范

## 必须遵守

### API 设计
- 所有输入参数放在 JSON 请求体中传递
- 所有 API 响应统一使用kissbot-api库定义的ApiResponse

### 配置文件
- 所有配置文件使用 JSON 格式存储

### 时间格式
- 时间格式使用 24 小时制：`yyyy-MM-dd HH:mm:ss`
- 日期格式：`yyyy-MM-dd`
- 年格式：`yyyy`

### 实体结构体

- 实体类结构体字段类型：除字符串外，所有实体类字段类型均使用 `Arc<T>` 包裹
- 字符串类型：在使用非mut String的地方，一律使用ArcStr
- 此规则旨在减少大对象在 Rust 的所有权传递中产生的复制开销

## 禁止
- API 路径中不嵌入动态参数
- 禁止使用&Arc<T>双重引用

### 注释
- 应只说明现状。禁止“已修改为”“替换为”“原……”等体现变化的描述
