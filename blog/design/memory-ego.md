# 自我认知设计

## 设计

- 提供通过 agent_id 和 role_name 的精确查询
- 提供通过 agent、role 描述的分词搜索

## 数据模型

### 客观设定
- **身份标识**：agent_id（手工指定）、描述、禁止事项、自主运行目标
- **个体识别信息**：个体列表，每项包含个体名称（代号）、身份（如所有者、管理员、或其他个体）、关联的消息通道（messenger + user）、与其他个体的关系、与其他个体的关系的描述

### 角色设定（每个 agent ID 对应多份）
- **角色扮演**：role_name（手工指定）、全名、描述、禁止事项、自主运行目标
- **角色间关系**：其他角色的role_name、该角色关联的个体名称、关系描述、关系类型
