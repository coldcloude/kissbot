# kissbot-memory 组件设计

## 概述
记忆基础模块，定义记忆系统的文件存储目录结构，提供目录管理和索引查询功能，以及路径构造接口，作为程序库供其他记忆模块（记忆存储模块、记忆结构模块、自我认知模块）使用。

记忆系统支持两种组织模式——角色记忆和事件记忆。两种模式共用同一套存储和索引机制，区别仅在于目录名的构造方式。推送方和查询方拼接角色标识或事件标识作为后缀传给记忆基础模块，由本模块构造完整路径。

## 核心功能

1. **目录管理**：管理记忆系统根目录和各 agent 的子目录结构，自动创建目录
2. **记忆索引**：为记忆记录构建和维护索引，支持按时间范围快速查询、索引过期处理和自动重建
3. **路径构造**：接收 `(agent-id, year, suffix)` 返回完整存储路径

## 内部模块

### 1. DirectoryManager - 目录管理器
- 管理记忆系统根目录
- 创建和管理 agent 目录及其子目录
- 通过检查 agent 标识文件判断目录有效性
- 提供 list_agents 查询所有有效 agent
- 目录自动创建

### 2. MemoryIndexer - 记忆索引器
- 为记忆记录构建和维护索引（记录在文件中的位置）
- 支持索引过期处理：小过期（新记录追加）、大过期（文件重写）
- 支持按时间范围快速查询
- 支持自动索引重建

### 3. PathBuilder - 路径构造器
- 提供路径构造接口：接收 `(agent-id, year, suffix)`，返回完整路径
- `suffix` 由调用方（nexus、memory-struct）拼接，本模块不做解析
- 提供路径构造方法

## 功能流程

### 路径构造流程
调用方传入 `(agent-id, year, suffix)` → PathBuilder 接收参数 → 拼接为完整文件系统路径 → 返回路径给调用方。

### 索引维护流程
记忆写入时 → MemoryIndexer 检查当前索引是否有效 → 小过期则追加索引记录 → 大过期则重建索引文件 → 索引更新完成。
