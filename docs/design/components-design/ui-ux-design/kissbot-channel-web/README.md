# 聊天主界面交互与布局说明（管理后台）

配合 [layout.html](layout.html) 和 [style.css](style.css) 使用，描述界面各区域的交互行为和数据展示逻辑。

> 本页面为管理员专用后台，普通用户不使用此界面。

## 页面结构

### 连接页
输入 API key 的登录页，连接成功进入主界面。

### 聊天主界面

#### 顶部标题栏（header）
- 左侧显示应用名称 "Kissbot Web Chat"
- 右侧显示当前用户信息和下拉菜单

#### 左侧 - 会话列表（sidebar）
- 展示所有群组（单聊群组 + 多人群组），无论 admin 是否已加入
- 当前选中的群组有高亮标记
- 未加入的群组在列表中展示，但发送输入框禁用
- 按最后消息时间排序
- 有未读消息标记
- 底部固定区域：群组管理和用户管理按钮，点击后右侧切换到管理界面

#### 右侧 - 消息区域（main）
- **顶部标题**：显示当前选中群组的名称
- **消息列表**（messages）：
  - 上行（admin → agent）和下行（agent → admin）消息展示区分
  - 自己消息对齐方式与对方消息不同
  - 分页加载历史消息
  - "思考中..."状态提示（agent 正在处理时）
- **底部输入区**（footer）：
  - 文本输入框
  - 附件上传按钮（图片和文件），上传时图片自动生成缩略图
  - 发送按钮

### 群组管理面板
展示所有群组的列表（admin-user 单聊群组不可操作，仅可查看消息）。支持新建群组、修改群组名称、管理成员、删除群组。

### 用户管理面板
展示所有普通用户列表。支持新建用户、重命名用户和删除用户。新建用户时自动生成与 admin 的单聊群组。

## 页面切换

左侧管理按钮点击后，右侧消息区域切换为对应管理面板。管理面板包含独立的操作界面，与聊天界面互斥。

## 与后端通信

- **操作型请求**：连接、发送消息、群组管理、用户管理、附件上传下载等操作，携带 API key 进行认证
- **实时推送**：通过长连接接收消息事件，支持断线自动重连

## 附件展示

- 图片：显示缩略图，点击展示原图
- 文件：显示文件名，点击下载
- 附件属性包含 key、文件名、类型、大小、是否有缩略图
- 上传时图片自动生成缩略图
