# Web 通道管理员界面原型说明

本目录包含 Web 通道管理员界面的原型，配合 [login.html](login.html)、[layout.html](layout.html)、[group-management.html](group-management.html)、[user-management.html](user-management.html) 与 [style.css](style.css) 使用。界面仅供管理员使用，普通用户不使用该界面。

> 术语说明：这里的「管理后台」指管理员的聊天后台，是通道客户端；与智能体配置界面、记忆管理界面这类配置工具不是同一个东西。

## 原型成熟度

- **正式版**：`login.html`，包含完整交互，交互细节以其中的脚本为准。
- **简易版**：`layout.html`、`group-management.html`、`user-management.html`，只展示布局结构，交互用自然语言描述。

## 连接页（login.html）

- **后端选择区**：展示若干预置后端，每项显示名称与完整地址；另有一项自定义地址输入。
- **密钥输入**：管理员连接密钥的密码输入框。
- **连接按钮**：提交后端地址与密钥，进入聊天界面。
- **交互**：点击预置后端项即选中该项；聚焦自定义地址输入或输入内容时，选中项切换到自定义地址；选中的后端项有高亮标记。

## 聊天主界面（layout.html）

- **顶部栏**：显示应用名称；右侧显示当前管理员名称与下拉菜单，菜单项为「重命名管理员」「群组管理」「用户管理」。
- **会话列表**：列出全部会话，包含管理员与各用户的单聊群组以及多人群组。单聊群组显示对应用户名；多人群组显示群组名并附带群组标记。每项展示未读消息数，切换到该会话时清零，数值超过上限时显示省略标记；列表按最新消息时间降序排列，当前选中项有高亮标记；未加入的群组同样展示，但输入区禁用。
- **消息区顶部**：显示当前会话名称。
- **消息列表**：按内容类型分别渲染——文本直接显示；图片显示缩略图，点击后查看原图；非图片附件显示文件链接，点击下载；复合消息在同一气泡内逐项渲染并分隔；系统消息以居中样式显示；无法识别的内容不显示。管理员消息靠右、用户消息靠左。首屏加载最近若干条，向上滚动到顶部时继续加载更早的记录。
- **输入区**：文本输入框、附件上传按钮、发送按钮。
- **交互**：选中会话列表中的一项后，消息区切换到该会话；未加入的群组只可查看消息，不能发送。

## 群组管理面板（group-management.html）

该面板替换消息区显示，通过顶部栏下拉菜单进入。

- **新建群组**：输入群组名称并点选成员后创建。
- **重命名群组**：选择群组后输入新名称提交。
- **管理成员**：选择群组后点选要加入或移除的成员并提交。
- **群组列表**：展示群组名称、标识与成员；管理员与用户的单聊群组不可操作并标注仅可查看消息；多人群组提供删除操作。
- **返回**：左上角返回按钮回到聊天界面。

## 用户管理面板（user-management.html）

该面板替换消息区显示，通过顶部栏下拉菜单进入。

- **新建用户**：输入用户名称后创建；用户标识由系统生成，创建时自动建立该用户与管理员之间的单聊群组。
- **用户列表**：展示用户名称与标识，支持重命名与删除。
- **返回**：左上角返回按钮回到聊天界面。

## 区域之间的关联

- 会话列表的选中项决定消息区显示哪个会话，也决定管理面板操作后的作用对象。
- 新建用户会同时产生该用户的单聊群组，因此会话列表随之增加一项。
- 修改群组名称或成员后，会话列表中的群组名称与成员信息同步更新。
- 管理员在当前会话中的身份与普通成员一致；群组管理、用户管理是界面额外提供给管理员的能力。

## 与实现的关系

`kissbot-channel-web-ui` 是按本目录原型实现的前端应用：页面结构、区域划分与类名沿用原型，实现中补齐了加载、错误与禁用等状态，示例数据与样式细节以实现为准。
