# 聊天主界面交互与布局说明

配合 [layout.html](layout.html) 和 [style.css](style.css) 使用，描述界面各区域的交互行为和数据展示逻辑。

## 布局结构

整体分三部分：顶部标题栏、左右分栏主体（左侧会话列表 + 右侧消息区域）、底部分隔区。

### 顶部标题栏（header）
- 左侧显示应用名称 "Kissbot Web Chat"
- 右侧显示当前用户信息和下拉菜单

### 左侧 - 会话列表（sidebar）
- 展示所有群组（单聊群组 + 多人群组），无论 admin 是否已加入
- 当前选中的群组有高亮标记
- 未加入的群组在列表中展示，但发送输入框禁用
- 按最后消息时间排序
- 有未读消息标记
- 底部固定区域：群组管理和用户管理按钮（仅 admin 可见）

### 右侧 - 消息区域（main）
- **顶部标题**：显示当前选中群组的名称
- **消息列表**（messages）：
  - 对方消息左对齐，显示发送者名称和气泡
  - 自己消息右对齐，仅显示气泡
  - 向下滚动加载更早的历史消息
  - 已加载的消息在切换群组再切回后仍然保留
  - "思考中..."状态提示
- **底部输入区**（footer）：
  - 文本输入框
  - 附件上传按钮（图片和文件）
  - 发送按钮

## 页面切换

左侧管理按钮点击后，右侧消息区域切换为对应管理面板。管理面板包含独立的操作界面，与聊天界面互斥。
