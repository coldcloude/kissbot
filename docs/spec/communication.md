# 组件间通信机制

> 通信双方的职责与时机见 `docs/design/system-design.md` 的「组件间通信」表；本文说明各通信方式的实现机制。

## 一、方式总览

| 方式 | 使用场景 | 机制要点 |
|------|----------|----------|
| HTTP 请求-响应 | agent 与记忆服务、模型服务、管理界面之间；Station 与子站之间（MCP）；Web 前端与 Web 通道之间 | 统一响应外壳、API key 认证、短连接；失败以响应或错误表达 |
| WebSocket 长连接 | agent 与通道服务端；记忆存储与摘要记忆（通知） | 统一信封（序号、类型、状态码、载荷）、心跳、断线重连、握手认证 |
| 服务端推送 | Web 通道向管理员界面推送消息 | 单向事件流、断线自动重连、keep-alive |
| 共享文件系统 | 记忆存储、摘要记忆、自我认知 | 同一记忆根目录；写入方刷新后读取方可见 |

## 二、HTTP 请求-响应

- 所有请求参数放在请求体中，路径不携带动态参数；响应统一为「成功标志 + 数据 / 错误信息」的外壳。
- 认证使用请求头中的 API key（见 `authentication.md`）；不同端点使用不同密钥。
- agent 侧对记忆存储的写入不是逐条同步请求：客户端把记录累积到队列，达到条数阈值或等待超时后合并为一次请求提交，并等待落盘结果；这使单条写入的最坏延迟约为「等待阈值 + 一次网络往返」。
- 失败处理按用途区分：
  - 记忆写入失败只记录日志，不重试、不阻塞对话；
  - 记忆读取失败返回空上下文，让对话继续；
  - 模型调用失败按配置重试（指数退避）；
  - MCP 工具列表失败只跳过该子站，工具调用失败作为该次调用的错误返回；
  - 管理接口的业务失败以成功响应 + 失败标志返回，只有认证失败使用 HTTP 401。

## 三、WebSocket 长连接

### 消息信封

所有消息使用统一信封：序号、类型、状态码、载荷。类型码的高位区段表达所属域（通道信息、绑定、收发消息、群组事件、上行消息、附件二进制、记忆通知），二进制帧在信封头之后接业务头与数据。请求与响应通过序号配对，推送消息使用服务端自增序号。

### 连接与心跳

- 连接建立时在握手阶段校验 API key，失败则拒绝建立连接。
- 双方每 5 秒发送一次二进制心跳；心跳的具体超时判定由 kai-ws 的心跳处理器负责。
- 框架不自动重连：连接关闭后由使用方决定是否重连，重连即新连接，绑定关系需要重建。

### agent 与通道的连接

- agent 作为客户端连接通道服务端，一个 agent 可以为多条通道各建一个连接（按输入身份涉及的 channel）。
- 连接建立后按配置的输入身份逐个绑定；断线后按配置的重连间隔重试，重连成功后重新绑定该通道上的全部输入身份。
- 下行发送成功后，agent 把响应中的消息标识记入「待回显」集合，收到同标识消息时视为自身回显并丢弃。

### 记忆通知

- 摘要记忆作为客户端连接记忆存储的独立通知端点，握手同样用 API key。
- 通知只携带位置信息（记忆范围、通道、该通道本批最后一条记录的位置）；订阅方按自己的水位读取共享文件。
- 投递语义是至多一次：发送失败的连接被移除，不补发、不持久化；订阅方断线期间的变化靠重连后的「全部记忆范围重扫」补齐。

## 四、服务端推送（Web 通道）

- 管理员界面向 Web 通道订阅一个事件流，认证同样使用请求头中的密钥。
- 通道在消息落盘后向所有已订阅连接广播消息；每个连接一个无界通道，发送采用「尝试发送，失败即剔除该连接」的策略，慢客户端丢消息而不阻塞写路径。
- 每 15 秒发送一次 keep-alive 注释帧；浏览器的推送客户端库负责断线自动重连。断线期间的消息不会补发，界面通过历史查询补齐。

## 五、共享文件系统

- 记忆存储、摘要记忆与自我认知共享同一个记忆根目录，各自只写自己的子目录（`memory-store/`、`memory-struct-summary/`、`memory-ego/`），摘要记忆直接读取记忆存储写入的原始记录文件。
- 写入方在写入后显式刷新文件，读取方才能立即看到；组件之间没有文件锁，也不假设跨进程的写入顺序，跨进程并发通过「各写各的目录」避免。

## 六、超时、重试与失败语义

| 链路 | 超时 | 重试 | 失败表现 |
|------|------|------|----------|
| 模型调用 | 按模型配置（默认 60 秒，单次请求） | 按模型配置（默认 3 次），指数退避；配置类错误不重试 | 本次对话轮次失败，不发送回复 |
| 模型列表查询 | 固定 30 秒 | 不重试 | 切换模型的命令失败，保持原模型 |
| MCP 客户端调用 | 按子站配置的超时 | 不重试 | 工具列表失败跳过该子站；工具调用失败返回错误结果 |
| 记忆写入 | 由批量队列与网络决定 | 不重试 | 记录日志 |
| 记忆读取 | 请求级超时 | 不重试 | 返回空上下文 |
| 摘要记忆定位 | 请求级超时 | 不重试 | 丢弃本批消息 |
| 通道请求 | 30 秒 | 不重试 | 返回错误，由调用方决定重连 |
| 附件分块 | 由连接决定 | 无 | 传输终止并清理路由 |

## 七、对外部署

各组件内部只使用 HTTP 与 WS；对外提供服务时由代理层转换为 HTTPS 与 WSS。因此组件不需要处理证书，也不需要在代码中区分内外网地址。
