# 记忆索引机制

> 对应设计文档：`docs/design/components-design/kissbot-memory.md`

## 存储顺序

记忆文件严格按照时间和序号排列消息：
- 每条消息按写入时间排序，时间精确到秒
- 一次写入多条时，时间相同，按照写入顺序生成递增序号
- 如果最后一条的时间晚于当前写入消息的时间，则判定为插入乱序

## 乱序处理

在插入乱序的情况下，强制重写文件：
1. 读取文件中所有记录
2. 按时间和序号重新排序
3. 更新序号为单调递增序列
4. 将重排后的记录写回文件
5. 触发重建级别变更通知

## 索引机制

### 内存索引

在内存中为记忆记录维护索引，提供按时间范围快速查询。

### 懒加载

索引使用懒加载机制：
- 收到变更通知时仅记录变更级别
- 记忆查询时才按级别重建索引
- 变更级别分两种：
  - **追加级别**：在旧索引基础上追加新记录
  - **重建级别**：重新构建整个索引（发生在文件重排或重建后）

### 变更通知对接

记忆结构实现模块可将 memory-store 的变更通知对接到 MemoryIndexer 的变更通知接口，由 MemoryIndexer 按懒加载机制自动处理索引维护。
