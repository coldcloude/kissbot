# kissbot-memory-struct 组件设计

## 概述
记忆结构框架，定义记忆结构构建的标准接口，供具体的记忆结构实现模块使用。记忆存储模块有新数据时通过 WSS 通知记忆结构实现模块，后者从共享文件系统读取后构建索引。

## 框架接口
定义标准接口规范，包括：
- 记忆结构构建接口
- 记忆搜索工具接口

## 记忆结构实现模块的工作方式

### 工作流程
1. 连接到记忆存储模块的 WSS 服务
2. 收到新数据通知后读取共享文件系统的记忆记录
3. 对每条记忆执行处理（如提取摘要、构建索引等）
4. 构建搜索索引文件
5. 提供搜索 API（由 agent 在 agentic loop 内通过 tool call 调用）

### 配置需求
各个实现模块可配置自己的处理参数（如摘要生成用的 LLM API 等）。

## 外部通信

| 对端 | 协议 | 通信时机 | 内容 |
|------|------|----------|------|
| 记忆存储模块 | WSS | 新数据到达时 | 接收通知 |
| 记忆存储模块 | 文件系统 | 持续 | 读取记忆文件 |
| agent | HTTPS (tool call) | agentic loop 内 | 提供记忆搜索 |
