# kissbot-agent 组件设计

## 概述
智能体核心组件，负责将消息通道的消息加工为 LLM 可用上下文，通过 agentic loop 调用 LLM 执行操作、生成回复。支持三种运行模式，是系统的中枢模块。

## 内部模块

### 1. ModeManager - 模式管理器
- 管理三种 agent 模式的切换和配置
- 根据不同模式加载相应的配置和组件

### 2. SessionManager - 会话管理器
- 问答模式：管理单个会话
- 工程模式：管理多个会话的创建和切换
- 自主模式：不使用会话，从记忆系统加载消息

### 3. ContextBuilder - 上下文构建器
- 根据当前模式构建发送给 LLM 的完整上下文（系统消息 + 对话消息）
- 自主模式：从自我认知模块读取设定构建系统消息，从记忆结构模块读取近期记忆
- 工程模式：从工程管理模块获取禁止事项、职位设定、指导文件等构建系统消息
- 问答模式：通用助手系统消息，不压缩对话历史

### 4. AgenticLoop - Agentic 循环
- 核心执行循环：调用 LLM API、处理 tool call、循环执行直到完成
- 上下文超长检查，触发压缩或重置

### 5. ToolManager - Tool 管理器
- 问答模式：仅加载获取信息的固定 skill
- 工程模式：加载文件操作、命令执行、扩展 skill
- 自主模式：加载记忆模块 tool 和扩展模块

### 6. MemoryPushManager - 记忆推送管理器
- 在 agentic loop 外将消息推送到记忆存储模块
- 推送内容：channel 消息、思考内容、工具调用指令和结果、回复文本

### 7. WSSClient - WSS 客户端
- 作为 WSS 客户端连接消息通道
- 接收来自通道的上行消息
- 发送下行消息（回复、绑定请求等）

### 8. HTTPSClient - HTTPS 客户端
- 与记忆存储模块、自我认知模块、记忆结构模块通信
- 调用 API 推送和查询记忆

## 三种模式的工作方式

### 问答模式
1. 只有一个会话
2. 系统消息为通用助手设定
3. tool 仅加载固定 skill
4. 对话消息不压缩
5. 不使用 agent-id，不加载自我认知模块

### 工程模式
1. 手动新建和切换会话
2. 系统消息包含：禁止事项（从工程管理模块获取）、职位设定、指导文件
3. tool 包含：文件操作、命令执行、扩展 skill
4. 可选加载记忆结构模块用于历史记忆
5. 上下文压缩方式：LLM 压缩生成墓碑消息，或丢弃已推送对话后重新读取记忆

### 自主模式
1. 没有会话概念，对话消息从记忆结构模块加载
2. 系统消息包含：禁止事项、客观设定和角色设定（从自我认知模块获取）、自主运行目标
3. tool 包含：记忆搜索、扩展模块
4. 长时间空闲时加载自主运行目标触发主动行为
5. 上下文超长或长时间未重置时执行重置：所有消息存入记忆存储模块 → 清空上下文 → 从记忆结构模块重新加载近期记忆

## 内部流程

### agentic loop 流程
1. 接收消息 → 加入会话/上下文
2. （在 agentic loop 外）推送到记忆存储模块
3. 检查上下文是否需要压缩/重置 → 需要则执行
4. 构建完整 LLM 上下文（系统消息 + 对话消息）
5. 调用 LLM API
6. 处理返回：有 tool call → 执行 tool → 推送 tool 结果到记忆存储模块 → 回到步骤 4；无 tool call → 生成最终回复
7. 推送思考内容和回复到记忆存储模块（在 agentic loop 外）
8. 将回复发送到消息通道

### 上下文重置流程
判断条件（自主模式）：上下文超长 / 长时间无消息 / 长时间未重置
执行：所有消息存入记忆存储模块 → 清空上下文 → 从记忆结构模块重新加载近期记忆

### 主动行为触发流程（自主模式）
空闲计时器超时 → 加载自主运行目标 → 信息收集或输出 → 结果推送

## 外部通信

| 对端 | 协议 | 通信时机 | 内容 |
|------|------|----------|------|
| 消息通道 | WSS | 持续 | 收发消息、绑定、附件下载 |
| 记忆存储模块 | HTTPS | 每条消息产生时 | 推送记忆记录 |
| 自我认知模块 | HTTPS | 启动时/重置时 | 读取自我认知设定 |
| 记忆结构实现模块 | HTTPS(tool call) | agentic loop 内 | 查询记忆 |
| 工程管理模块 | 库调用 | 工程模式 | 获取职位设定/tool |
