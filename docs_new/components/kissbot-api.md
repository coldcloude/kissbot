# kissbot-api 组件设计

## 概述
API 定义模块，定义各模块间通信的标准数据结构和统一的 API 响应格式。是模块间数据交换的契约层。

## 内部模块

### 1. kinds 模块
基础类型接口定义：字符串类型、映射类型、集合类型的抽象

### 2. common 模块
通用 API 类型：统一的 API 响应结构

### 3. ego 模块
自我认知模块相关的所有 API 定义：
- Agent 管理请求/响应（创建、查询、更新、搜索、复制等）
- 用户识别信息请求/响应（获取、替换、重命名、更新权限等）
- 角色设定请求/响应（创建、查询、更新、关系管理等）

### 4. store 模块
记忆存储模块相关的所有 API 定义：
- 记忆推送请求
- 记忆查询请求/响应

### 5. channel 模块
消息通道模块相关的 API 定义

## 设计原则

### 数据结构一致性
通过泛型保证并发类型和序列化类型在编译时一致：
- 内部模块可使用优化类型
- API 通信使用标准类型
- 通过泛型定义 → 接口约束 → 具体实现的体系保证一致性

### 直接序列化
并发容器类型可直接序列化和反序列化，无需转换。

## 对外接口
以库形式提供标准数据类型，供所有其他模块依赖。
