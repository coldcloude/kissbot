# kissbot-channel-web 前后端联调测试

## 环境准备

### 1. 初始化 workspace

```bash
cd /home/admin/project/kissbot
rm -rf test/workspace && mkdir -p test/workspace
cp -r test/workspace-template/* test/workspace/
```

### 2. 启动后端服务

```bash
cd /home/admin/project/kissbot/test/workspace
../../kissbot-channel-web/target/debug/kissbot-channel-web
```

确认输出包含：
```
kissbot-channel-web HTTP server listening on 127.0.0.1:8301
```

### 3. 启动前端 dev server

新开一个终端：

```bash
cd /home/admin/project/kissbot/kissbot-channel-web-ui
npm run dev
```

确认输出包含 `http://localhost:5173`。

### 4. 浏览器访问

使用 agent-browser 技能打开 `http://localhost:5173`。

## 测试用例

### TC-01：登录页展示

**前置**：浏览器已打开 `http://localhost:5173`

**步骤**：
1. 验证页面顶部显示应用名称 "Kissbot Web Chat"
2. 验证显示 "管理后台" 副标题
3. 验证后端 URL 列表显示预置选项：
   - "生产环境"（大字）+ `https://api.kissbot.example.com`（小字）
   - "测试环境"（大字）+ `http://localhost:8301`（小字）
   - "开发环境"（大字）+ `http://192.168.1.100:8301`（小字）
4. 验证 "测试环境" 选项有高亮边框
5. 验证有 "Admin Key" 密码输入框
6. 验证有 "连接" 按钮

**预期**：各元素正确渲染

### TC-02：登录失败

**前置**：TC-01 通过

**步骤**：
1. 点击 "测试环境" 选项，确认选中状态
2. 在 "Admin Key" 输入框输入 `wrong-key`
3. 点击 "连接" 按钮

**预期**：页面显示错误提示，不进入主界面

### TC-03：登录成功

**前置**：TC-02 通过

**步骤**：
1. 点击 "测试环境" 选项，确认选中状态（高亮边框）
2. 清空 Admin Key 输入框
3. 输入 `admin-key-123`
4. 点击 "连接" 按钮

**预期**：
- 成功进入聊天主界面
- 顶部标题栏左侧显示 "Kissbot Web Chat"
- 顶部标题栏右侧显示 "管理员 ▼"

### TC-04：会话列表显示

**前置**：TC-03 通过

**步骤**：
1. 验证左侧会话列表显示以下会话：
   - `助手小A`（admin-user 单聊组，显示用户名）
   - `助手小B`（admin-user 单聊组，显示用户名）
   - `开发组 群组`（多人群组，显示群组名 + 群组标记）
   - `项目X 群组`（多人群组，显示群组名 + 群组标记）
2. 验证没有会话右对齐显示未读数
3. 验证会话按最新消息时间排序（此时无消息，顺序不限）

**预期**：4 个会话正确显示，单聊组显示用户名，多人群组显示群组名 + 群组标记

### TC-05：主界面默认状态

**前置**：TC-03 通过

**步骤**：
1. 验证右侧主区域显示 "选择一个会话"

**预期**：默认无选中状态

### TC-06：选中会话并发送文本消息

**前置**：TC-03 通过

**步骤**：
1. 点击左侧会话列表中的 `开发组 群组`
2. 验证右侧顶部标题显示 `开发组`
3. 验证消息区域为空
4. 在底部输入框输入 `你好`
5. 点击发送按钮（或按 Enter）

**预期**：
- 消息区域显示发送的消息，靠右显示（蓝色气泡）
- 显示消息时间

### TC-07：SSE 实时推送

**前置**：TC-06 通过

**步骤**：
1. 保持当前页面打开（不要刷新）
2. 在另一个终端使用 curl 模拟 agent 回复：

```bash
curl -s -H "X-Api-Key: admin-key-123" -H "Content-Type: application/json" \
  -X POST -d '{
    "messenger_id": "web",
    "user_id": "user-1",
    "group_id": "dev-team",
    "msg_type": "text",
    "content": {"Text": "你好，有什么需要帮助的吗？"}
  }' \
  http://127.0.0.1:8301/api/message/send
```

3. 观察浏览器页面

**预期**：
- 浏览器页面自动收到新消息，显示在消息区域
- 消息靠左显示（灰色气泡），发送者为 `user-1`
- 会话列表中 `开发组 群组` 右对齐显示未读数 `1`

### TC-08：未读消息清零
